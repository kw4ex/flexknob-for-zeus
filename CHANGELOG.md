# Changelog

## 1.0.1
- The knob's serial lines (DTR/RTS) are switched on when it is opened, as the earlier bridge did, so more knobs start reliably.
- The knob's first messages are logged to help diagnose a knob that does not respond.

## 1.0.0
- First release: the FlexControl knob for Zeus. Turning tunes VFO A; a press switches to AF volume, AGC gain, VFO B, RIT, XIT, tuning step or TX drive; twelve presses run a function you choose; optional Elecraft KPA1500 functions.
